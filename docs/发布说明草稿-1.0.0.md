# TongZip 1.0.0 发布说明（RC 草稿 · 待验收定稿）

> 状态：**草稿**。须随 RC 验收工作表区块四逐项核后方可对外。任何修改需重新对齐冻结清单（rc-freeze.json）。

## 关于本版本

TongZip 1.0.0 是面向 Windows 10/11（**仅 x64**）的免费桌面压缩解压工具，完全本地处理，不上传任何用户文件。

**支持架构**：x64。**暂不提供也不承诺原生 ARM64 支持**——ARM64 设备可通过 x64 模拟运行，但未经验证，不视为官方支持。

## 格式支持

引擎：内置 7-Zip 21.07 独立版命令行工具（7za.exe）。**"无法解码"与"无法创建"是两类不同的限制**：

### 可打开并解压（读取）
7z、zip（含 zipx 的 deflate 常规成员）、tar、gz/tgz、bz2、xz、lzma/lzma86*、cab、分卷（.7z.001 等）、以及 zip 容器类（jar/epub/docx/xlsx 等）。
*lzma/lzma86 读取以引擎声明为准，正样本验证尚在进行（见已知限制）。

### 可创建
7z、zip、tar、tar.gz、tar.bz2、tar.xz、分卷。

### 无法打开也无法创建（引擎不含解码器，应用会明确提示、不会静默）
**RAR / RAR5 / ISO / ZSTD(.zst) / WIM / ESD / SWM**。需要打开 RAR/ISO 请安装官方 7-Zip 或 WinRAR 后由其处理。

### 可读但无法创建
lzma / lzma86（独立版能力边界）、zipx（扩展编码成员）、zstd 单文件流。

## 密码与加密

- **7z**：支持 AES-256 加密创建，支持含中文在内的任意字符密码，可加密文件名。
- **zip**：支持传统 ZipCrypto 创建与解压；**密码仅限 ASCII 可打印字符**（中文密码会被应用提前拦截并提示改用 ASCII 密码或 7z 格式，不会静默失败）。
- **tar/gz/bz2/xz 族**：格式本身不支持加密。填写密码会被应用**明确拒绝并提示**（不会假装加密）。

## 已知限制（有条件接受，逐项披露）

1. **无自动更新**：当前版本仅提供"检查更新"提示，**没有自动下载、校验与安装能力**；收到提示后需手动前往发布页下载新版本。
2. **安装包未数字签名**：首次运行可能触发 Windows SmartScreen"未知发布者"警告。选择"仍要运行"即可；签名将在后续版本评估引入。
3. **大文件资源占用**：在 4GB 单文件、默认压缩档位的实测条件下，引擎峰值内存约 2.5GB。该数据**仅适用于该测试条件**（x64 单机、默认参数），不代表所有归档类型与硬件的表现；低内存设备建议使用更大分页文件或小批次压缩。
4. **RAR/ISO 等只读不可用**：因引擎边界（见格式支持节），说明书早期"RAR 只读"目标在本版未实现。
5. **卸载行为**：卸载会清理 TongZip 自身的右键菜单/文件关联注册项，**不会改动**您为任何文件类型选择的默认应用；个人数据（设置与任务历史）当前默认保留在 %APPDATA%\TongZip，如需彻底清除请手动删除该目录。

## 安全能力摘要

恶意路径/压缩炸弹/链接条目防护并熔断、归档修改事务保护（失败不损坏原档）、异常退出后任务状态恢复且**绝不自动重放**、密码不落日志/历史。
